# Установщик ПРОМЕТЕЙ CRM для Windows (1.4.2)

**Для пользователя:** двойной щелчок по `PrometeyCRM-Setup-1.4.2.exe` — и всё. Ничего вводить и подтверждать не нужно,
права администратора не требуются. Через минуту CRM открывается в браузере, на экране установщика — логин
`admin@prometey.local` и временный пароль (при первом входе CRM попросит задать свой).

## Что делает установщик
1. Ставит программу в `%LOCALAPPDATA%\Prometey` (папка пользователя, без UAC):
   `app\` — CRM, `runtime\node.exe` — встроенный подписанный Node.js 24, `data\` — база, документы, резервные копии, журнал,
   `prometey.env` — настройки и пароли (доступ только у владельца), `install.json` — сведения об установке.
2. Автозапуск при входе в Windows (`HKCU\...\Run\PrometeyCRM` → `node.exe app\scripts\windows-launcher.js --detach`),
   ярлык «ПРОМЕТЕЙ CRM» на рабочем столе и в «Пуске», пункт в «Параметры → Приложения» для удаления.
3. Запускает CRM и проверяет `/api/health`.

После установки работает только `node.exe` (подписан Node.js Foundation) — антивирусы (в том числе 360 Total Security)
его не блокируют. Своих .exe после установки не остаётся.

## Повторный запуск установщика
- Обновляет программу: автоматическая резервная копия, данные и пароли сохраняются.
- «Забыли пароль руководителя? Выдать новый временный» — новый временный пароль для `admin@prometey.local`.

## Управление сервером
В CRM: «Администрирование → Сервер» — адреса, доступ из офисной сети (вкл/выкл; Windows один раз спросит разрешение
для Node.js), перезапуск, резервная копия сейчас, список копий, журнал. Сторож (`windows-launcher.js`) перезапускает
сервер при сбое и делает резервную копию раз в сутки (хранит 30 дней).

## Удаление
«Параметры → Приложения → ПРОМЕТЕЙ CRM → Удалить». Данные остаются в `%LOCALAPPDATA%\Prometey\data` и подключатся
при повторной установке. Удалить всё: `node windows-uninstall.js --all`.

## Сборка
```
NODE_EXE=/путь/к/node.exe CRM=../crm ./build.sh
```
Нужны Go 1.22+ и Python 3 (ресурсы: иконка и сведения о версии). Результат: `dist/PrometeyCRM-Setup-<версия>.exe`
и `dist/prometey-setup-linux` (для проверок). Проверки: `node test/e2e.js` (37 проверок), `node test/ui.js` (Playwright).

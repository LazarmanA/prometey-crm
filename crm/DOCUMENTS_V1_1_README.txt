ПРОМЕТЕЙ CRM — обновление документов 1.1

В карточке сделки → «Документы» доступны:
1. Договор
2. Договор-счёт
3. Счёт на оплату

Данные заказчика подставляются из связанной карточки компании (ИНН, КПП, наименование, адрес), данные исполнителя — из раздела Документы → Реквизиты организации. Техника, ставки, количество и НДС подтягиваются из сделки. Перед выпуском доступен предпросмотр.

Если компания по ИНН отсутствует в CRM, её сначала нужно добавить: внешний реестр ФНС/DaData без подключенного API-ключа не используется. Реквизиты необходимо проверить до подписания.

Для установки поверх существующей версии: сделайте резервную копию папки storage и используйте обновлённые файлы программы; не перезаписывайте существующую папку storage. Обновление полной серверной версии, не Windows EXE.

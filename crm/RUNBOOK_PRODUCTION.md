# ПРОМЕТЕЙ CRM 1.0 — Production Runbook

## Перед первым запуском

1. Использовать постоянный Linux-сервер/VPS с резервным диском.
2. Создать `.env` из `.env.example` и заменить все `CHANGE-ME` на реальные длинные пароли.
3. Не хранить `.env` в Git.
4. Обеспечить HTTPS reverse proxy перед приложением.
5. Подключить постоянный volume `/data`.

## Контроль после запуска

Проверить `/api/health`. Нормальный ответ содержит:

- `ok: true`
- `database: "ok"`
- `storage: "ok"`
- `pdfReady: true`
- `pdfEngine: "libreoffice"`
- `version: "1.0.0"`

Затем проверить вход руководителя, создание тестовой сделки, счёта, скачивание PDF и выход из системы.

## Backup

Перед каждым обновлением и минимум раз в сутки выполнять полный backup. Хранить минимум одну копию вне сервера CRM.

Backup включает:

- SQLite;
- PDF документов;
- записи звонков;
- manifest.

## Обновление

1. Полный backup.
2. Остановить контейнер.
3. Обновить код/образ.
4. Запустить контейнер.
5. Проверить health.
6. Проверить вход и один документ.
7. При проблеме вернуть предыдущий образ и backup.

## Аварийные признаки

Не принимать рабочие данные, если:

- `/api/health` возвращает 503;
- `database != ok`;
- `storage != ok`;
- `pdfReady != true`;
- сервер не может создать backup.

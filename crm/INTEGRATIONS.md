# Интеграции 0.5

ПРОМЕТЕЙ CRM 1.0 использует серверные секреты интеграций. Перед доступом из интернета обязательны HTTPS, резервное копирование и сетевое ограничение административного контура. Учётные данные production задаются только через переменные окружения.

Руководитель открывает «Интеграции», проверяет связь, просматривает пакет, затем отдельно нажимает «Отправить этот пакет». Загрузка страницы, проверка связи и просмотр ничего не изменяют во внешних системах. Экспортируются активные компании и связанные активные сделки; архив не передаётся. Нет автоматического обмена, обратной загрузки оплат, удаления внешних записей или синхронизации стадий. Журнал текущего процесса хранится в памяти.

## Битрикс24

Создайте входящий вебхук с правами CRM. На сервере задайте BITRIX24_WEBHOOK (полный HTTPS URL вида https://portal.bitrix24.ru/rest/USER/SECRET/) и PROMETEY_SOURCE_ID (постоянный уникальный идентификатор этой установки, например prometey-company-prod). Перезапустите сервер. Не меняйте идентификатор после первого обмена: он вместе с локальным ID предотвращает дубли. Не используйте один идентификатор для разных установок. Не запускайте несколько процессов обмена одновременно.

Компании и сделки сопоставляются через ORIGINATOR_ID + ORIGIN_ID, используя crm.company.list/add/update и crm.deal.list/add/update. При неоднозначном сопоставлении обмен останавливается. Новые сделки попадают в стандартную воронку. Существующие стадии не изменяются. Название, сумма, связь с компанией и комментарии экспортированных записей обновляются. Комментарии этих записей принадлежат интеграции и перезаписываются.

ИНН, телефон, email и адрес передаются текстом в COMMENTS компании; это не заполнение штатных телефонных полей или банковских реквизитов. Даты, вид/принадлежность техники и строки работ передаются в COMMENTS сделки. Сумма сделки — количество × ставка клиенту, без добавления внутренних расходов. Сопоставление пользовательских полей, реквизитов, воронок и менеджеров требует отдельной настройки.

После частичного сбоя повторите пакет: уже созданные записи будут найдены по внешним ID. При тайм-ауте сначала убедитесь, что предыдущая операция на стороне Б24 завершена; не запускайте параллельный повтор. API Б24 не даёт этому адаптеру гарантии exactly-once.

Официальные методы: https://apidocs.bitrix24.com/api-reference/crm/companies/crm-company-add.html и https://apidocs.bitrix24.com/api-reference/crm/deals/crm-deal-add.html

## 1С: контракт HTTP-сервиса

Это универсальный отправитель JSON, не готовое расширение для любой конфигурации 1С. Программист 1С должен опубликовать HTTP-сервис, реализующий контракт ниже, и сопоставить компании и сделки со справочниками и документами конкретной конфигурации. Без такого сервиса реальный обмен не заработает. В поставке нет обработчика, который создаёт бухгалтерские документы.

Серверные параметры: ONEC_EXCHANGE_URL=https://server/base/hs/prometey/ и ONEC_TOKEN (Bearer-токен, проверяемый сервисом), а также PROMETEY_SOURCE_ID. Сертификат HTTPS должен быть доверенным. Не отключайте проверку TLS. Секреты задаются в окружении процесса или менеджере секретов, не в браузере и не в архиве проекта.

POST health с JSON {"schema":"prometey.exchange.v1"} должен вернуть HTTP 200 и {"ok":true,"schema":"prometey.exchange.v1"}.

POST exchange получает JSON:
- schema: prometey.exchange.v1
- source: постоянный ID установки
- requestId: UUID пакета
- companies: id, name, inn, phone, email, address
- deals: id, number, name, companyId, address, start, end, comment, equipmentType, ownership, items
- items: equipmentId, equipment (модель), start, end, quantity, saleRate, purchaseRate, extras (внутренние расходы), unit.

Все даты передаются как записаны в CRM; даты/время без часового пояса интерпретируются по согласованному часовому поясу предприятия. Денежные ставки в рублях. Сервер 1С обязан проверять типы, связи и права, применять пакет транзакционно, дедуплицировать source+requestId и обновлять записи по source+id. Ответ HTTP 200 {"ok":true,"requestId":"тот же UUID"} означает, что весь пакет применён. При повторном UUID вернуть то же подтверждение без повторного создания документов. Ошибки вернуть HTTP 4xx/5xx. Частичный успешный ответ не поддерживается. Время ответа — до 15 секунд, иначе отправитель фиксирует неопределённый исход и разрешает повтор с тем же UUID в пределах 10 минут.

Кнопка «Скачать JSON» позволяет выгрузить пакет без подключения. Такой файл не является стандартным CommerceML и сам по себе не импортируется штатной кнопкой любой 1С.

Официальная основа: https://v8.1c.ru/platforma/http-servisy/ и https://v8.1c.ru/platforma/json/

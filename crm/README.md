# ПРОМЕТЕЙ CRM 1.0

Операционная CRM для аренды и субаренды спецтехники. Релиз 1.0 собран из проверенной ветки 0.10 и доведён до закрытого production-пилота одной компании.

## Что работает в 1.0

- роли руководителя и менеджера с серверной проверкой доступа;
- компании, сделки, объекты, несколько единиц техники в одной сделке;
- собственная и наёмная техника;
- назначения, смены, часы, простой и переработка;
- плановая и фактическая экономика: оборот, себестоимость, прибыль и маржа;
- рабочие столы компаний и сделок, заметки, задачи, ссылки и общий чат сделки;
- импорт/экспорт контактов CSV с проверкой и дедупликацией;
- журнал звонков, загрузка и защищённое хранение MP3/WAV;
- открытый шлюз телефонии для Mango, Билайн, МТС, T2 и custom-провайдеров;
- интеграционные шлюзы 1С и Битрикс24;
- счета и договоры: предпросмотр, уникальная нумерация, НДС, PDF, реестр, статусы оплаты;
- единицы счёта: смена, час, рейс, единица, сутки, машино-час, км, тонна, м³;
- формирование счёта по плану сделки и по фактическим сменам;
- привязка одного документа к компании и сделкам без дублирования файла;
- audit log;
- SQLite WAL, транзакции и полное резервное копирование;
- health-check `/api/health`.

## Контур запуска

Версия 1.0 предназначена для **закрытого пилота одной компании на постоянном сервере**. Данные, PDF и записи звонков должны лежать на постоянном диске/volume. Для массового многопользовательского SaaS с независимыми организациями запланирован отдельный PostgreSQL + RLS контур.

Для запуска требуется Node.js 24+ и LibreOffice Writer для генерации PDF. Рекомендуемый способ — Docker из этого репозитория.

## Production-учётные данные

Демо-пароли `director` / `manager` в production заблокированы, даже если ранее были захешированы. При production-запуске обязательны переменные:

- `PROMETEY_ADMIN_EMAIL`
- `PROMETEY_ADMIN_PASSWORD` (минимум 12 символов)
- `PROMETEY_MANAGER_EMAIL`
- `PROMETEY_MANAGER_PASSWORD` (минимум 12 символов)

Пароли хранятся только как scrypt-хеши. Сессии сохраняются в SQLite как SHA-256 хеш токена; браузер получает HttpOnly SameSite=Strict cookie.

## Данные и файлы

В Docker-контуре:

- БД: `/data/prometey.sqlite`
- PDF: `/data/documents`
- записи звонков: `/data/recordings`

`storage/data.demo.json` используется только как начальный seed при первом создании базы. Рабочая БД и пользовательские файлы не входят в Git.

## Проверка релиза

Главный release gate:

```bash
npm run test:release
```

Он проверяет синтаксис, базовую CRM-логику, БД, рабочие столы, чат/контакты, звонки, телефонию, интеграции, безопасность, документы и production runtime.

Быстрый браузерный smoke через установленный Chromium/Chrome (без npm-зависимостей):

```bash
npm run test:browser
```

Если Chromium/Chrome установлен нестандартно, задайте `PROMETEY_CHROME=/path/to/chrome`. Полный исторический Playwright-набор сохранён как `npm run test:browser:playwright` и требует отдельно установленный пакет Playwright.

## Резервное копирование

```bash
npm run backup
```

Создаётся отдельный каталог с консистентной копией SQLite, PDF, аудиозаписями и `manifest.json`. Для реальной эксплуатации этот скрипт нужно запускать по расписанию и копировать backup на другой физический носитель/объектное хранилище.

## Интеграции

Все секреты задаются только на сервере. Шаблон переменных находится в `.env.example`.

- Яндекс Карты — `YANDEX_MAPS_API_KEY`.
- Битрикс24 — `PROMETEY_SOURCE_ID`, `BITRIX24_WEBHOOK`.
- 1С — `PROMETEY_SOURCE_ID`, `ONEC_EXCHANGE_URL`, опционально `ONEC_TOKEN`.
- Телефония — `TELEPHONY_GATEWAYS`.

Если внешняя интеграция не настроена, основная CRM продолжает работать и показывает модуль как неподключённый.

## HTTPS

Для доступа из интернета CRM должна работать за HTTPS reverse proxy. `COOKIE_SECURE=auto` автоматически ставит Secure cookie, когда прокси передаёт `X-Forwarded-Proto: https`. Не публикуйте порт 3030 напрямую в интернет без TLS и сетевого ограничения.

## Ограничения 1.0

См. `KNOWN_LIMITATIONS.md`. Это не скрытые ошибки, а функции, которые требуют внешнего провайдера или следующего SaaS-этапа: нативные API операторов телефонии, GPS/ГЛОНАСС, ЭДО, банковская сверка, Prometey AI и PostgreSQL multi-tenant.


## Быстрая работа (1.3.1)

| Клавиши | Действие |
|---|---|
| `/` или `Ctrl+K` | Поиск по компаниям и сделкам |
| `N` | Создать запись в текущем разделе |
| `Alt+1 … Alt+9` | Перейти к разделу меню |
| `Ctrl+Enter` | Сохранить открытую форму |
| `Esc` | Закрыть форму |
| `?` | Подсказка по клавишам |

Адрес раздела сохраняется в строке браузера (`/#/orders`), поэтому работают закладки, обновление страницы и кнопки «Назад/Вперёд».

# Лиды и контроль работы с клиентами — версия 1.2

Новый раздел «Лиды»: источник, ответственный, обязательное следующее действие и срок, история контактов, контроль просрочек (также по существующим компаниям и задачам в рабочем столе), поиск дублей по ИНН и телефону, статусы.

API: GET/POST /api/leads, GET/PATCH /api/leads/:id, GET/POST /api/leads/:id/events, POST /api/leads/:id/convert.

Интеграции звонков/сайта: пока требуются конфигурация провайдера и подписанные webhooks. **Автоматическое создание лидов от реального звонка или с сайта ещё не подключено.** Для работающих интеграций требуются проверки подлинности вебхуков и обработка повторных событий.

Перед первым запуском сделайте резервную копию существующей SQLite-базы. Архив — исходный код серверной версии, не Windows EXE.

# ПРОМЕТЕЙ CRM — защита

## Что встроено
| Угроза | Защита |
|---|---|
| Подбор пароля | 8 ошибок с адреса для логина / 30 с адреса / 20 на логин → блокировка 15 мин; в nginx ещё 10 попыток/мин |
| Подмена IP | `X-Forwarded-For` учитывается только при `TRUST_PROXY=1`, берётся адрес от своего прокси |
| Утечка паролей | scrypt с солью; демо-пароли в рабочем режиме запрещены; пароль от 12 символов |
| Угон сессии | токен 256 бит, в базе только SHA-256; cookie HttpOnly + SameSite=Strict + Secure по HTTPS; до 20 входов на пользователя |
| CSRF | SameSite=Strict + проверка Origin/Referer для изменяющих запросов |
| XSS | экранирование вывода + Content-Security-Policy (скрипты только с сервера) |
| Кликджекинг | `X-Frame-Options: DENY`, `frame-ancestors 'none'` |
| Чужие данные | менеджер видит только свои сделки, объекты и компании; журнал, модули, интеграции, телефония, реквизиты — только руководитель |
| Обход путей | статика только из `public/`, без скрытых файлов и неизвестных типов |
| Перегрузка | лимиты частоты, размер запроса 4 МБ (записи звонков 20 МБ), таймауты медленных соединений |
| Вебхуки телефонии | ключ от 32 символов на шлюз, сравнение без утечки по времени |
| PDF | данные экранируются, загрузка любых файлов из шаблона запрещена |

## Настройки (`/etc/prometey.env`)
- `PROMETEY_ADMIN_EMAIL/PASSWORD`, `PROMETEY_MANAGER_EMAIL/PASSWORD` — задаются командой `prometey passwords`.
- `TRUST_PROXY=1` — только если CRM стоит за своим nginx на том же сервере (установщик ставит сам).
- `API_RATE_LIMIT_PER_MIN`, `ANON_RATE_LIMIT_PER_MIN`, `WEBHOOK_RATE_LIMIT_PER_MIN` — лимиты частоты.
- `SESSION_TTL_HOURS` — срок входа (установщик ставит 12 ч).

## Проверка
`node tests/attack-test.js` и `node tests/xss-browser-test.js` (или `npm run test:full`).

## Что остаётся за вами
- Работать только по HTTPS (домен + `prometey https`).
- Не давать никому пароль root сервера; лучше вход по SSH-ключу.
- Раз в неделю скачивать бэкап с сервера к себе.
- При увольнении сотрудника — сменить пароли (`prometey passwords`): в этой версии у менеджера общая учётная запись.
